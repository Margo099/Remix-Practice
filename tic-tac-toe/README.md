# 🎮 Tic-Tac-Toe Online

Многопользовательская онлайн-игра "Крестики-нолики" с интеграцией Telegram-бота (@PlayPromo_Bot).

🔗 **Live Demo:** [https://tic-tac-toe7.ru](https://tic-tac-toe7.ru)

---

## 📋 Описание

Классическая игра "Крестики-нолики" с возможностью играть онлайн с AI. Система токенов обеспечивает безопасный доступ к игровым комнатам, а Telegram-бот отправляет уведомления о результатах игры. При победе игрока на экране появляется рандомный 5-значный промокод на скидку и отправляется сообщение в Telegram-бот «Победа! Промокод выдан: [код]»

При проигрыше отправляется сообщение в Telegram-бот «Проигрыш» и на экране появляется предложение сыграть ещё раз

При ничьей отправляется сообщение в Telegram-бот «Ничья»

---

## ✨ Основные возможности

- 🎯 **Классический геймплей** — игра 3x3 для двух игроков
- 🔐 **Система токенов** — безопасное создание игровых сессий, с AI по умолчанию
- 🤖 **Telegram-интеграция** — генерация и отправка токенов через бота
- 🎨 **Адаптивный дизайн** — работает на всех устройствах, адаптивно
- ⚡ **Быстрая валидация** — автоматическое определение победителя и ничьей
- 📊 **Redis-хранилище** — хранение токенов с TTL

## 🚀 Быстрый старт

### Установка зависимостей

```bash
# Сервер
cd server
npm install

# Клиент
cd ../client
npm install
```

### Настройка окружения

Создайте `.env` в папке `server`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен
TELEGRAM_CHAT_ID=ваш_chat_id
REDIS_URL=redis://localhost:6379
TOKEN_TTL_MS=300000
PORT=3000
API_SECRET=your_secret_key
```

### Запуск

```bash
# Запустите Redis
redis-server

# Запустите сервер
cd server
npm start

# Запустите клиент (в новом терминале)
cd client
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173)

## 🎮 Как играть

1. Откройте [https://tic-tac-toe7.ru](https://tic-tac-toe7.ru)
2. Получите токен через Telegram-бота или создайте новую игру
3. Поделитесь токеном с другом
4. Играйте по очереди- побеждает тот, кто первым соберёт 3 символа в ряд!

## 🔧 API

### `POST /api/validate-token`
Проверка валидности токена игровой сессии.

**Request:**
```json
{
  "token": "abc123"
}
```

**Response:**
```json
{
  "valid": true
}
```
